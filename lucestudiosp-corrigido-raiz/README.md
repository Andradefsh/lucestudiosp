# Luce Studio — réplica do site

Projeto Node.js + Express + EJS reconstruído a partir do material fornecido do site Luce Studio.

## Executar

```bash
npm install
npm start
```

Depois acesse `http://localhost:3000`.

Rotas principais:
- `/`
- `/empresa`
- `/portifolio`
- `/produtos`
- `/midia`
- `/faleconosco`

A rota `/contato` redireciona para `/faleconosco`.
